Made-up copy, for the fixture only. Scroll down: each block fades up as it enters the viewport, staggered by its inline --iv-i. Without JavaScript every block is visible from the start, and so it is under prefers-reduced-motion.

01

The first block is already in view

Entering also fires iv-edge-glint, so the border is drawn once as the card arrives.

02

Eighty milliseconds later

The delay is --iv-i multiplied by the stagger option, written as --iv-reveal-delay.

03

One observer for the whole container

The component keeps a single IntersectionObserver; no scroll listener, no layout read.

04

Seen once, left alone

With repeat off the element stops being observed as soon as it has entered.

05

Threshold at fifteen per cent

A block counts as arrived when 15 % of it is visible; the threshold option moves that line.

06

Destroy puts the markup back

The attribute and the delay are removed, and so is the style attribute when nothing else was using it.
