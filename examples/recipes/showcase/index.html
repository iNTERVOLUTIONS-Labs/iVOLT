Six photographs, one viewer

Each tile is a link to its own file, so the gallery works before any script does. With the script, a click opens the full-screen viewer at that image: arrows walk the set, Z zooms, Esc closes and focus returns to the tile you came from.

Four rules the framework keeps

The deck below sticks as you scroll past it. Where the engine has CSS scroll-driven animations the card underneath also shrinks and dims; where it does not, it is still a deck and nothing is lost.

01

Contracts before code

Every family is written down first — markup, classes, options, events, accessibility and what is out of scope — and only then implemented.

02

One grammar

Classes start with iv-, custom properties with --iv-, attributes with data-iv- and events with iv:. Nothing else gets in.

03

HTML that already works

The served markup is complete. JavaScript upgrades it and restores it on destroy; it never creates the thing the page is for.

04

Motion with an argument

Movement is transform and opacity, it has a reason, and prefers-reduced-motion removes it while leaving the composition whole.

Three steps that send nothing

Demonstration only. This wizard has no server behind it: nothing is submitted, no message is sent and nothing you type leaves this browser tab. The fields validate in the browser so the steps can refuse to advance, and the last button only says the flow is complete.

Where it actually is

The real milestones of the package, taken from its changelog. Every one of them is marked unreleased there: nothing has been published to a registry and nothing has been deployed. No dates are given because the changelog gives none.

  1. 2026 · unreleased

    v0.1 — Foundations

    Tokens, layers, the utility matrix and the first components. The grammar is fixed here and has not moved since.

  2. 2026 · unreleased

    v0.2 — Forms and data

    Forms, validation, tables and the data table: the parts a real application asks for first.

  3. 2026 · unreleased

    v0.3 — Overlays

    Dialog, drawer, dropdown, tooltip, popover and the command palette, all on one focus and layering model.

  4. 2026 · unreleased

    v0.4 — Surfaces and effects

    Textures, glass, glints, proximity lighting and reveals — the light of the system, with a static fallback throughout.

  5. 2026 · unreleased

    v0.5 — Composition

    Hero, carousel, megamenu, picker, datepicker and the theme builder; then a full visual review of the site.

  6. 2026 · unreleased

    v0.6 — Structure

    Navbar, stepper, declarative toasts, timeline, stat and avatar, plus the expressive layer of tokens. The figures above were measured here.

  7. 2026 · in progress

    v0.7 — Media and motion

    The gallery and viewer, scroll-driven motion, text effects and the countup — this page is the recipe that composes them.
