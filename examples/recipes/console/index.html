Arclight Console is fictional. It is a demonstration page for the iVOLT framework: no utility, substation, feeder, crew, reading or timestamp on it is real, it is not connected to anything, and it sends, stores and fetches nothing. The command palette, the table and the forms operate only on the text that was served with the page.

Built with the published package: ivolt.min.css and auto.js, plus one local stylesheet. No photographs are used on this page.
