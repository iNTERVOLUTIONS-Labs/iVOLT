01

The practice

Four rules we keep. They are the rules of the framework this page is built with, which is the only honest thing an example can claim.

Draw the contract before the thing

Markup, class names, options, events, keyboard behaviour and what is deliberately out of scope are written down first. Implementation is what is left after the argument is over.

The served page already works

Every control here is complete HTML before a script runs. The gallery is a list of links, the wizard is a stack of sections, the menu is a list. JavaScript upgrades them; it never invents them.

Motion needs an argument

The cover lags behind the scroll because a cover is further away. The rule beside this paragraph lights up when the paragraph arrives. Ask for reduced motion and all of it stops, with the composition intact.

Nothing leaves the page

No fonts, no analytics, no third-party scripts, no network requests at all. The photographs sit in a folder next to this file and are credited in its README.
