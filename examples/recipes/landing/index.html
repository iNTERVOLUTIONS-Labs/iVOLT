Benefits

Three claims about the framework this page is built with, not about a client.

No build step

One stylesheet and one optional module. Copy the folder, open the file, edit the text.

Tokens, not overrides

Colour, spacing and radius come from custom properties, so a rebrand is a token change.

Accessible defaults

Native elements first: dialogs, disclosures and tables keep the behaviour the browser already gives.

This band is scoped to the dark theme

Only this section carries data-iv-theme="dark". The rest of the page still follows the operating system, which is what the theme scoping rule of the framework is meant to demonstrate.

Frequently asked questions

Is this a real company?

No. Northwind Studio is an invented name used to show a complete page. Nothing on this page describes a real product, customer or result.

What happens when I submit the contact form?

Nothing leaves the browser. The dialog closes and no request is made; there is no server behind this page.

Does the page work without JavaScript?

The content does. The accordion is built on <details>, and the contact dialog falls back to a static block reached through its anchor link.

Why is only one answer open at a time?

The disclosures declare data-iv-exclusive="true", so opening one closes its siblings inside the same accordion.
